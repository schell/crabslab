# Phase 6: Cleanup and Dependency Removal

**Status:** Pending
**Estimated effort:** 2-3 days
**Prerequisites:** Phase 5

## Overview

Remove all SPIR-V infrastructure, add wgsl-rs dependencies, remove the old
`#[derive(SlabItem)]`, clean up workspace configuration, update documentation,
and update CI.

---

## 6.1 Remove SPIR-V infrastructure

- Remove `spirv-std` from all `Cargo.toml` files
- Remove the `[patch.crates-io]` spirv-std entry from workspace `Cargo.toml`
- Remove `wgpu`'s `"spirv"` feature from workspace dependencies
- Remove `[package.metadata.rust-gpu.*]` from
  `craballoc-test-shaders/Cargo.toml`
- Remove the `.spv` file and `manifest.json` from
  `craballoc/src/test/shaders/`
- Remove all `#[cfg(target_arch = "spirv")]` /
  `#[cfg(not(target_arch = "spirv"))]` blocks
- Remove `#![cfg_attr(target_arch = "spirv", no_std)]` from all crates
- Remove `#![allow(unexpected_cfgs)]` where no longer needed

---

## 6.2 Add wgsl-rs dependencies

- Add `wgsl-rs` (with `linkage-wgpu` feature where needed) to:
  - `crabslab`
  - `craballoc-test-wire-types`
  - `craballoc-test-shaders`
- Update workspace `[workspace.dependencies]` for wgsl-rs

---

## 6.3 Remove old `#[derive(SlabItem)]`

Once all types use `#[slab_item]`, remove the old `SlabItem` derive macro from
`crabslab-derive`.

---

## 6.4 Remove the excluded `shaders` directory reference

Remove the `exclude = ["./shaders"]` line from the workspace `Cargo.toml`.

---

## 6.5 Update documentation

- Update `README.md` files to reference wgsl-rs instead of rust-gpu
- Update `AGENTS.md` guidelines
- Update `SESSION.md` or archive it
- Update crate descriptions in `Cargo.toml` (e.g., remove "rust-gpu" from
  `crabslab`'s description)

---

## 6.6 Update CI

- Evaluate whether Vulkan driver installation is still needed in CI (wgpu tests
  still run on GPU, so likely yes)
- Remove any `cargo-gpu` references
- Ensure `cargo test` runs all WGSL validation tests (auto-generated by
  `#[wgsl]` modules with imports)
